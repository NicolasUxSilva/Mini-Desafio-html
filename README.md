📋 Sobre o Projeto

Este projeto foi desenvolvido como parte de um desafio de Desenvolvimento Web, com o objetivo de praticar a estruturação de páginas utilizando HTML5 semântico.

A página representa um portfólio de um estudante de Desenvolvimento de Sistemas, apresentando suas habilidades, projetos realizados e um formulário para contato.

🎯 Objetivos
Praticar a estrutura básica do HTML5;
Utilizar tags semânticas;
Criar uma navegação com links internos;
Organizar informações em uma tabela;
Criar um formulário de contato;
Trabalhar com imagens, links e listas;
Desenvolver uma página organizada e funcional.
